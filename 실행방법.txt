========================================
  알약 앱 - 바로 실행하는 방법
========================================

1) ZIP 압축을 풀어 폴더로 들어갑니다.

2) 터미널(명령 프롬프트)을 열고 그 폴더로 이동합니다.
   예) cd 폴더이름

3) 처음 한 번만 설치:
   npm install

4) 앱 실행:
   npm run dev

5) 브라우저에서 주소 열기:
   http://localhost:5173

----------------------------------------
추가 테스트 (선택)
----------------------------------------
검색 폼 자동 테스트:
  npm run stress-test

사진 인식 자동 테스트:
  npm run stress-test:scan

실사 사진으로 테스트하려면
  test-fixtures/scan/ 폴더에 png/jpg 사진을 넣고
  npm run stress-test:scan
  을 다시 실행하세요.
