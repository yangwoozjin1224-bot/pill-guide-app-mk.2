# Migration 001 — Recognition Feedback (local schema v1)

**Type:** Client localStorage schema (no server DB)  
**Key:** `pillguide:feedback`  
**Version:** `schemaVersion: 1`

## Purpose
Store user corrections when recognition is wrong (Phase 4 active-learning loop stub).

```json
{
  "id": "fb_1710000000000_ab12",
  "createdAt": 1710000000000,

  "correct": {
```

## Privacy (MUST)
- **Do not** permanently upload original photos to a server without explicit user consent.
- Default: `consentImageStore=false` → `imageDataUrl` is null.
- Even with consent, only a **downscaled JPEG thumbnail** may be stored locally.
- This client store is for developer review / future training export — not a production PHI vault.

## Upgrade
- If entry `schemaVersion` ≠ 1 → skip in readers.
- Breaking changes → add `002_*.md` and migrate in code; do not edit this file in place.
