# 저시력 고령자를 위한 AI 알약 인식 앱

## Android (주 타깃)

네이티브 Android 앱은 [`android/`](./android/) 폴더입니다.

- Kotlin + Jetpack Compose + Material 3
- CameraX, Hilt, MVVM, Room, Retrofit
- 자세한 내용: [android/README.md](./android/README.md)

**Android Studio에서 `android/` 폴더를 Open** 하세요.

## 웹 (레거시 참고)

기존 React + Vite + Tailwind 웹 구현은 저장소 루트에 남아 있습니다.
신규 기능·배포는 Android 프로젝트를 기준으로 진행합니다.

```bash
npm install
npm run dev
```
